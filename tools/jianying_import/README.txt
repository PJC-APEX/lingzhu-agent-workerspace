灵珠剪映导入工具（Windows 64 位 EXE）

1. 下载并双击 LingzhuJianYingImporter.exe，无需安装 Python 或依赖。
2. 点击“选择”，找到网页下载的素材包 ZIP，无需手动解压素材包。
3. 确认剪映草稿目录，不同于默认目录时点击“选择”修改。
4. 点击“生成剪映草稿”，等待完成提示。
5. 导入成功后打开/重启剪映，在草稿列表中找到“灵珠草稿-...”并检查。

剪映草稿目录不是默认位置时，直接在窗口中选择实际草稿目录。

素材会复制进新草稿自己的 materials 目录。成功后可删除下载包，不要删除草稿中的 materials。
导入工具无需云端账号密码、模型密钥或 OSS 密钥。不会自动渲染 MP4；剪映内确认后自行导出视频。
剪映版本兼容性需要在目标版本实测。本工具不会自动导出 MP4。
