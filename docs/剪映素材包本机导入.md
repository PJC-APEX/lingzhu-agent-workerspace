# 云端下载与 Windows 本机导入

## 用户操作

1. 云端对话中完成图片审核并上传配音和 SRT。素材包模式会创建一个视频导出任务。
2. 等任务完成，点击任务卡里的“下载剪映素材包”。下载失败会在卡片显示原因，可重试。
3. 点击“下载 Windows 导入工具.exe”，双击下载的 EXE，无需安装 Python、解压工具或安装依赖。
4. 在工具窗口选择网页下载的素材包 ZIP，并确认或选择本机剪映草稿目录。
5. 点击“生成剪映草稿”，等待进度提示。工具会将所有素材复制到新草稿内，成功后显示结果并打开草稿所在目录。
6. 打开或重启剪映，从草稿列表找到新生成的“灵珠草稿-...”并检查，然后在剪映里导出 MP4。

自定义草稿目录在窗口中选择。默认目录为当前 Windows 用户的剪映专业版草稿位置，并不保证覆盖所有自定义安装/剪映版本，请按实际设置确认。

导入成功后可以删除 ZIP，不能删除草稿的 materials 目录。工具不需要账户、模型或 OSS 密钥，也不会自动渲染视频。EXE 适用于 Windows 64 位；当前未签署代码签名，Windows 可能显示未知发布者提示。

## 配置与实现

- 本机后端默认 `JIANYING_EXPORT_MODE=local`，继续直接生成本机草稿。
- Compose 显式设置 `JIANYING_EXPORT_MODE=package`：Agent 不在 Linux 容器写用户草稿，转为创建视频任务；完成后按已有下载接口打包。
- `application/jianying_export_service.py` 负责验证图片审核和关联归属、写任务及 Outbox。相同对话/图片任务/字幕 ID 的重试复用现有视频任务。任务失败仍使用现有任务重试操作。
- `GET /api/v1/jianying/importer` 需登录，返回已构建的 `releases/windows/LingzhuJianyingImporter.exe`；缺少产物时返回 503，不再提供 Python 源码包。不会包含项目配置或密钥。
- 素材包接口复用已有任务，尚不在数据库中保存 ZIP；每次下载从已审核资源重新打包。此步骤的存储临时故障返回 502。
- 前端视频任务卡显示下载入口；保留旧 JSON 下载能力。
- Linux 容器镜像复制 Windows 构建产物以提供下载，不在 Linux 中交叉编译 EXE。

## 开发者构建

在 Windows 开发机安装 `tools/jianying_import/build-requirements.txt`，运行 `tools/jianying_import/build_windows.ps1`，输出 `releases/windows/LingzhuJianyingImporter.exe`。脚本策略限制时可直接执行脚本中对应的 Python PyInstaller 命令，无需修改系统策略。构建包含 Tk 窗口运行时、pyJianYingDraft 模板、pymediainfo DLL 和图片依赖。

构建后运行 `.venv\Scripts\python.exe scripts/verify_windows_importer.py`：将 EXE 复制到隔离目录，从 PATH 中移除 Python、清除 Python 环境变量，执行真实图片、音频和字幕导入，并检查草稿内媒体路径。产物已 gitignore，发布/构建服务器镜像前需先在 Windows 构建，再将 EXE 放入该路径。

## 验证范围

自动测试覆盖非法 ZIP 路径、版本/文件限制、工具包脱离仓库执行帮助命令、素材与时间范围传入、导入工具鉴权、Agent package 模式任务创建和重复提交复用。使用真实 pyJianYingDraft SDK、有效 PNG/WAV/SRT 生成了草稿，检查 JSON 中所有媒体路径均存在且位于持久 materials 目录。

尚未在用户目标剪映桌面版本打开验证，也未在完全未安装 Python 的全新 Windows 虚拟机中验收；当前完成的是独立 EXE 在隔离 PATH/cwd 下的真实导入测试。历史已经完成的本机直出消息没有视频任务 ID，不会自动补生成下载任务，需在 package 模式重新执行导出流程。
