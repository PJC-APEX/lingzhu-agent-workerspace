# 旧代码清理

本批只删除无生产引用的旧实现，不合并或改变仍提供服务的对话入口。

## 删除清单

- `workflows/dispatcher.py`：只有说明文字，无代码与引用。
- `workflows/normal_rewrite.py`：无引用的纯转发，实际改写用例已直接调用能力层。
- `agents/tools/video_generation_tool.py`：无引用的旧演示 JSON 草稿生成器。
- `agents/graph.py` 中的 `StreamingAgentState`、`_stream_response`、`streaming_agent_graph`、`stream_agent_response` 及专用导入：没有生产调用，只剩一条专项测试。
- `tests/test_rewrite_model.py` 中只验证上述废弃流式图的测试；生产主图与 SSE 的现有测试保留。
- `application/document_service.py` 的 `guess_media_type`、`cleanup_upload_artifact` 以及由此闲置的 import：无引用。
- `application/agent_prompt_service.py` 的 `default_storyboard_prompt` 及导出名：无引用，默认提示词在实际使用的解析函数中提供。

## 保留

- `agents/graph.py` 的非流式图：现有 POST messages 仍使用它，不可随清理一并删除。
- `agents/context.py`、`agents/memory_tasks.py`、演示图片和分镜工具：仍有生产调用。
- `services/jianying_export.py`：当前仅有专项测试调用，但它是一项完整的云端导出能力；本次保留，是否退役应单独决定。
- `agent_prompt_service.py` 和 `prompt_service.py`：分别负责图侧降级策略与提示词版本用例，不是简单的重复文件。
- 空包初始化文件、旧 __pycache__ 和已有恢复包不作为业务重复文件删除；恢复包继续保留。
