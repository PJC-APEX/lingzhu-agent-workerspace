# 云端剪映素材包接口

本批提供 `GET /api/v1/jobs/{job_id}/jianying-package`。需登录；只允许读取当前用户拥有、已完成的视频任务。

应用层根据视频任务关联的 `subtitleFileId` 和 `imageJobId` 校验同一对话/工作区，要求图片任务已完成且每个分镜有且仅有一张已审核图片。随后按字幕 cue 重新生成时间线，打包 `manifest.json`、`timeline.json`、原始 SRT、配音及所有图片。ZIP 内素材保存在 `materials/`，时间线引用 ZIP 内 `materials/...` 相对路径；下载响应结束会清理服务端临时包。

资源归属或素材缺失返回 404/409，不暴露其他用户的任务。OSS/本地存储文件无法读取时返回明确的 409。接口不修改视频任务、ExportFile、审核状态或队列；不增加数据库表。原 JSON 时间线下载仍保留。

本批尚未加入前端下载按钮，也未实现 Windows 本机导入脚本。当前可通过登录态调用该 API 下载 ZIP；要从 ZIP 生成并打开剪映草稿，需要后续完成本机导入工具并在 Windows 剪映中实测。

验证：成功包包含清单、时间线、SRT、音频及图片；测试了跨用户访问拒绝、任务未完成拒绝、图片未审核拒绝和存储失败清理。
