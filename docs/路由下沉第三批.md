- `api/v1/exports.py`：112 → 25 行，只调用应用用例并返回文件响应。

- `application/subtitle_service.py`：上传限流、文件类型/大小/字幕校验、配音包选择、存储与数据库写入协调。Session 在执行上传的线程内部创建和关闭，输入显式携带 user_id，无 FastAPI 对象。
- `application/media_service.py`：导出归属、私有素材及预览定位，保留当前用户/工作区前缀与历史工作区前缀兼容，以及本地预览目录限制。

- `infrastructure/file_io.py`：本地文件、限量流写入、临时目录和 ZIP。

- `application/download_file.py` 返回文件路径、类型、名称、响应头和清理目录；`api/v1/files.py` 才创建 FileResponse/BackgroundTask，在响应结束后清理临时文件。
- 删除已无调用方的 `services/asset_service.py`，复用应用层工作区归属边界。

## 保留行为与有意修正

接口路径、方法、入参、响应结构、错误文案/状态、排序、去重、ZIP 内部命名、媒体类型和私有响应头保持兼容。字幕仍限制 10MB，音频仍限制 512MB，按块写入音频。

这批同时修正两类失败资源泄漏：

1. 字幕/配音包部分上传成功而后续上传或数据库写入失败时，回滚数据库，尽力删除已返回引用的存储对象，并清理本地暂存；清理失败记录日志，不掩盖原始失败。
2. 下载准备发生非 HTTP 异常（如 ZIP 写入异常）时，也清理临时目录。成功下载只清理临时副本，保留源素材；本地导出和本地私有媒体不挂接源文件删除。

远程上传已经发生但适配器尚未返回引用的未知结果，不保证可以补偿；本批没有实现跨存储/数据库的分布式事务。
